# LichessStudy Hybrid v7.0 — 完整国际象棋专业术语库深度集成版

针对机器翻译在国际象棋领域常见的误译与前后不一致问题，v7 版本内置了 **220+ 条有序国际象棋专业词条前置注入与后置清洗引擎 (`ChessGlossaryProcessor`)**：
1. **彻底消除阵营误译**：`White` / `Black` 严格统一译为 **白方 / 黑方**（复合词自动识别为 `白王/黑王`、`白后/黑后`、`白格/黑格`、`白子/黑子`），绝不再出现“白人/黑人/白色/黑色”。
2. **彻底消除将军与将杀恶译**：`mate` / `checkmate` / `mating attack` 严格译为 **将杀 / 杀棋 / 攻王杀势**（绝不译为“交配/配偶”）；`check` / `gives check` / `with check` / `in check` 严格译为 **将军 / 带将 / 被将军**（同时智能区分日常短语 `check out` -> `查看`），绝不译为“检查/支票”。
3. **100% 统一六大棋子译名**：全篇强制统一为 **王 (`King`)、后 (`Queen`)、车 (`Rook`)、象 (`Bishop`，含白格象/黑格象/双象)、马 (`Knight`)、兵 (`Pawn`，含通路兵/孤兵/叠兵/落后兵)**，绝不再出现“主教、骑士、城堡、菜鸟、王后、女王、国王、典当、卒”混杂的情况。
4. **精准还原棋盘几何与战略术语**：`square` -> `格`（绝不译为广场）、`open file / e-file` -> `开放线 / e线`（绝不译为文件）、`back rank / 7th rank` -> `底线 / 第七横线`（绝不译为后排/排名）、`the exchange` -> `半子`、`variation` -> `变例`。
